# 🤖 BotdeAutomacao-Wpp-Telegram-Facebook

Sistema de automação desenvolvido para captura, tratamento e divulgação automatizada de ofertas em múltiplas plataformas.

O projeto realiza leitura inteligente de links de afiliados, identificando automaticamente informações relevantes da oferta e publicando conteúdo formatado em grupos e canais.

---

# 🚀 Funcionalidades

- Captura automatizada de ofertas
- Identificação de nome do produto
- Reconhecimento automático de preços
- Detecção de cupons disponíveis
- Tratamento e formatação de dados
- Publicação automatizada no WhatsApp
- Publicação automatizada no Telegram
- Criação automática de posts no Facebook
- Integração entre múltiplas plataformas
